# Kavsar Uyi · Ipakchi — 3D

Interactive 3D presentation of the Kavsar Uyi "Ipakchi" house (Asmakon).
Built with Three.js: orbit view, floor-by-floor cut views, top-down plan, room list, first-person walk, day/evening lighting. UZ / RU / EN.

- `npm install && npm run dev` — local preview
- `npm run build` — static site in `dist/` (published on the `gh-pages` branch)

Model: exported from Blender (`Kavsar_uyi_ipakchi_blender.blend`), optimized with glTF-Transform (meshopt + WebP).
